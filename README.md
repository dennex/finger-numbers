# Kids Games

A small collection of kid-friendly web games.

## Run

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included

- `subtraction/`: Treasure Rescue Subtraction, with practice from 2 to 6 digits
- `fingers/`: Finger Numbers, for learning numbers from 0 to 10 with fingers
- Static PWA files suitable for GitHub Pages
